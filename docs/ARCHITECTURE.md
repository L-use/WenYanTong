# 初版架构

界面采用 Kotlin + Compose + Material 3 自定义主题，Navigation Compose 负责路由。`AppViewModel` 暴露 `StateFlow<AppState>`，界面使用生命周期感知收集；所有数据库和资源校验工作在 IO 协程执行。重复查询取消上一协程。

底栏切换清理首页以上的返回栈，并进入所选根页面；不会恢复已退出的释义、练习等子流程。输入和学习数据由共享 ViewModel 与本地数据库保留。设备测试覆盖“关联练习 → 设置 → 阅读设置 → 首页”的回归路径。

`LocalRepository` 管理两份分离的 SQLite 数据：只读 `sample-0.1.0.db`（词条、义项、对照、例句、题目），与 `personal.db`（历史收藏、答题快照、错题）。初版以 SQLiteOpenHelper 实现个人数据，尚未引入 Room；后续迁移必须保留原数据与表结构，不能清库替代迁移。模式和阅读偏好用应用私有 SharedPreferences 保存。

资源从 APK assets 首次复制到私有目录，比较 manifest SHA-256，检查 integrity_check 与 user_version 后打开。当前仅内置一个合并示例包。独立四类包的 ZIP 安装、签名索引、current 版本切换、回滚尚未实现；不要把内置复制器视为在线更新器。

查询先标准化标点、空白、英文大小写，再对已收录对照全文匹配。古文与双语支持反向匹配。只有完整匹配才展示译文。文言方向可额外返回输入中命中的字词，并标明字词命中不等于整句译文命中。无逐句 sense 标注时列候选义项，不声称唯一语境义。

练习从 question.entry_id 精确过滤；无上下文时综合组卷。题库不足按实际数量显示。提交时用事务保存答案与错题，提交按钮禁止并发。答对错题不会自动移除错题本。报告基于本次答题快照生成。

当前 AppState 的输入、结果与进行中的练习支持配置变更，尚不支持系统杀进程后恢复进行中的练习；已提交答案、错题、历史收藏和设置持久保存。后续使用 SavedStateHandle 恢复会话，并拆分按 feature 的 ViewModel。

数据库版本：资源 schema=1，个人库=1。这是首次建库，无旧版迁移。未来升级需增加明确迁移，当前 onUpgrade 遇到未知版本主动失败，不做破坏性清库。

0.2.0 新增两个独立 feature：update 负责 GitHub 描述读取、受限 HTTPS 下载和 APK 签名校验；storage 负责 JSON 用户备份与系统文档选择器。更新联网不进入学习查询 Repository。个人库 schema 仍为 1，无破坏性迁移；备份记录合并使用事务，阅读与运行偏好随后恢复。发布通过本机签名脚本完成，CI 不持有私钥。
