# 初版验证计划

## 自动验证

- Python 构建：SQLite integrity_check、外键、资源统计、题目答案范围、真实哈希。
- JVM 单元测试：标点与大小写标准化、禁止部分句子声称精确译文、无效答案判分。
- Android 仓库测试：内置 SQLite 安装、“之”四义项与关联题、已知与未知句、双向对照、收藏与错题跨实例持久保存、INTERNET 权限不存在。
- Compose 设备流程：输入“之”、打开释义、进入练习、提交答案显示解析。
- Android lint 与 debug APK 构建。

## 人工验收

首页输入“之”，查看四个义项并打开关联练习；题量五题但库存四题时，进度应为四题。选择错误答案，提交后显示正确答案与解释；完成后报告准确，错题可复练。重复提交不得重复计数。

首页推荐句显示收录译文、篇章与解析；未知输入显示无译文提示。四方向标签、输入提示和历史方向一致。“你好”可查 Hello；反向 hello 可查中文；其他英文无命中时不伪造结果。

收藏、重启查看、取消收藏、删除确认；深色/浅色/跟随系统与字号持久化。最大字号及横屏检查浮层可滚动、底部按钮不被裁切。无网络时所有初版功能可用。

本计划描述验证目标，实际执行结果见开发交付说明；未执行的检查不能标为已通过。尚未实现的功能（AI、OCR、在线包管理）不包含在本轮通过范围。
