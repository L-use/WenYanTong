文言通 0.6.0：双向互译、多题型、错题编辑与用户 Skills。

- 翻译入口简化为“中英互译”和“文言白话互译”，自动判断方向；“本地资源”标签仅在离线模式显示。
- 所有查询都有练习入口，包含未收录的中文、英文或古文查询；配置 API 后可按当前查询在线生成，不再要求必须先有本地词条。
- 练习可选单选、判断和选词填空；仍支持离线题库。无对应离线题目时明确提示，不替换为无关题目或自动联网。
- 错题本显示题目列表，支持编辑题干、选项、正确答案及解析，修改后用于复练并可备份恢复。
- AI 设置新增添加 API、API 管理、命名、切换、编辑和删除；每个配置独立保留加密 Key、模型及最近连接成功状态。
- Skills 管理显示内置技能和自建技能，支持创建、编辑、启停、删除及选择翻译/练习作用范围；自建技能可随用户数据备份恢复。
- 处理重复 Unicode 转义造成的乱码，拦截损坏编码与无效字符；历史受损错题可手动修订。编辑页适配软键盘，顶部固定保存按钮。

真实 AI 请求需填写自己的 API Key，可能产生服务商费用。未收录内容生成的题目会标注基于查询的 AI 参考，不代表词库收录或人工审校。保留原有签名、学习记录和 10 个独立下载资源包；全程本地构建发布，不使用 Actions。
