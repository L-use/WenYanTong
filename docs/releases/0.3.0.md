文言通 0.3.0：独立离线资源更新。

- 离线资源页支持检查 GitHub 资源更新、下载并安装资源包，显示下载状态及安装结果。
- 支持通过 Android 文件选择器导入固定格式 ZIP；校验路径、大小、SHA256、数据库结构、引用关系和应用兼容版本。
- 安装完成立即刷新词典、古文和练习，可点击“查看词条”“查看古文”。个人历史、收藏和错题保持独立。
- 提供可下载常用基础库 1.0.0：32 词条、36 义项、35 组文本对照（含两组双语示例）、34 道单选题。应用保留原内置小型示例库，无网络也能使用；下载基础库后扩充内容。古文为常用节选，释义、译文与题目为项目原创，未经专业学术审校。
- 开发者可本地构建并发布资源 ZIP 和独立资源索引，无需 GitHub Actions，也无需为每次内容更新发布 APK。

学习查询仍是本地收录匹配，尚未实现任意文本 AI 翻译。GitHub 不可达时可继续使用内置资源或手动导入 ZIP。
