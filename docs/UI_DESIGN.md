# 初版视觉与交互

主背景 #FAF9F5，正文 #25211E，次要文字 #746D66，分隔线 #E6DFD8，次级面 #F3EFE7。陶土色 #CC785C 为视觉参考；为提高白字按钮和浅底正文对比度，实际主操作色加深为 #AE5B40。深色模式使用独立色板。

页面间距 24dp，卡片圆角 20dp，按钮圆角 16dp。正文默认 18sp，可调整 16–26sp，同时响应系统字体缩放。古文标题使用系统 serif，正文使用系统 sans；未捆绑商业字体。无水墨背景装饰，重点放在阅读、留白和内容层次。

底栏：首页、练习、历史、设置。首页语言与模式各自下拉；结果页原文有链接字词并提供 48dp 词项按钮；释义使用可滚动 Bottom Sheet。页面长内容可滚动。交互图标提供说明；装饰图标不重复朗读。

初版实现功能对应 U01–U07 的本地子集、U11/U12/U19/U20/U21、U22/U23、U24 的资源说明、U27/U34；不宣称完整实现全部 34 页。AI 页清楚说明未接入，不提供无效 API 表单。未使用大面积模糊或额外复杂动画。
