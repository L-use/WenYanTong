文言通 0.6.1：修复 AI 出题失败。

- 修复仅选择单选题时，模型返回未选题型导致“AI 题型与所选范围不符”的问题：请求只说明所选题型，提供对应的有效 JSON 示例。
- 兼容“单选题”“single_choice”等常见名称；仅选择一种题型且模型漏写类型时，依据所选类型继续校验完整结构。
- 收到题型或格式不合要求的题目后，最多自动重新生成一次；仍不合要求时给出可操作提示。认证、网络失败不自动重试，取消后停止请求。
- 保留选项数、唯一答案和来源校验，不将不合要求的题目强行改名放行。出题期间固定题型及题量，避免界面选择与请求不一致。
