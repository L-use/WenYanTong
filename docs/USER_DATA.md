# 本地路径与用户数据备份

设置 → 数据与存储显示实际 APK 安装文件、应用私有目录、personal.db、资源目录、偏好目录和更新缓存路径；每项可复制。这些路径由 Android 分配，APK 位置可能在升级后改变，私有目录通常不能从普通文件管理器直接访问。

导出和导入使用安卓系统文件选择器，无需申请广泛存储权限。用户选择本机或自己信任的文件提供方。导出为可阅读的 JSON，包含历史与收藏、答题快照、错题、阅读/运行偏好及自动更新偏好；不包含 APK、资源库、下载缓存、API 密钥或发布签名材料。

导入前解析完整文件并显示数量，用户再次确认后合并。历史按 query+direction 去重，保留收藏并取较新时间；答题按 sessionId+questionId 去重，保留已有快照；错题计数取较大值，待巩固状态优先。已有记录不清空。阅读与运行偏好按备份恢复，导入本身不触发联网检查。

格式为 `wenyantong-user-data`，schemaVersion 1。当前上限 20 MB、三类记录合计 50,000 条。未知格式、越界字段、不支持的 schema 和不完整 JSON 在数据库事务前拒绝。记录合并在事务内完成，偏好随后保存。

备份不携带题库；跨资源版本导入的错题仍保留记录，但复练需要相应题目资源。当前提供合并导入，不提供清空当前数据的替换导入。
