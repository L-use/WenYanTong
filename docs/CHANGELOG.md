# 阶段变更

## 0.5.0 英文包、分类与 AI

新增两个独立英文词汇包，线上共 10 包，按中文/英文和资源类型筛选下载。词条命中直接展示释义与来源。支持加密保存兼容接口及 Claude 渠道配置，按当前查询与已安装词库生成练习，保存 AI 错题快照并支持备份恢复。正式签名覆盖升级和公开更新下载验证通过。真实付费渠道需用户配置 Key 后测试。

## 0.4.0 多包选择和全局查词

8 个资源包单独下载、更新和删除；迁移旧基础库。全局查词合并同字入口、按需读取释义并保留各包与字段来源。新增分页古文目录和长篇分段阅读。独立 resources-v2 索引及逐包发布脚本，与 APK latest 分离，不使用 Actions。来源、授权和限制见 USER_RESOURCE_COLLECTION.md、MULTIPACK_RELEASE.md。

## 0.3.0 独立资源更新

新增资源索引检查、用户点击下载、下载状态与取消、ZIP/数据库校验、只读库切换、立即浏览词条和本地 ZIP 导入。默认离线检查先确认联网，个人记录保持独立。提供可下载基础库 1.0.0（32 词条、36 义项、35 组对照、34 题）及本地资源发布脚本；不依赖 Actions。资源来源及发布步骤见 RESOURCE_PACK.md、RESOURCE_SOURCES.md。

## 0.2.0 更新渠道与用户数据

新增 GitHub 稳定版检查、说明、下载进度、取消与系统安装；校验哈希、包名、版本和签名。默认允许联网的模式每天最多自动检查一次，离线模式手动确认。新增本地路径显示与复制、JSON 用户数据导出、导入预览及事务合并去重。保留 schema=1 与初版签名，可覆盖升级。

源码部署到公开 WenYanTong 仓库；本机发布脚本负责验证、签名并上传完整发布附件，全程不使用 Actions，私钥不上传 GitHub。验证记录见 VALIDATION_0.2.0.md。

## 0.1.0 初版

目标：完成离线“之 → 多义项 → 真实出处例句 → 关联练习”的可运行学习闭环。

新增原生 Compose 工程、暖白/深色主题、底栏与导航；示例 SQLite 构建与校验；四方向已收录对照、点字释义；单选练习、判分解析、报告与错题；历史收藏与阅读设置。提供资源构建脚本、单元/设备测试及 CI。

回归修正：底栏首页清理旧子流程返回栈；最大字号可滚动至释义底部按钮；深色浮层系统栏与选中态使用一致的暖色方案。构建、3 项 JVM 测试、2 项资源测试和 3 项模拟器测试通过；lint 无错误。详情见 VALIDATION.md。

数据库为首版 schema=1，无旧版迁移。源码 MIT，原创资源 CC0。当前 AI/OCR/在线资源管理/其他六种题型为后续计划。
