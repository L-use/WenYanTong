# 0.6.0 学习与 AI 管理

## 两种互译入口

首页仅显示“文言白话互译”和“中英互译”，不再要求选四个方向。中英按文字特征初判；文言/白话按语言特征和已收录正反对照判断。AI 翻译可在当前语言组合内返回纠正后的方向，不能切换到另一组合。短词可能本身存在歧义，不保证离线启发式等同语言模型判断。

搜索框和结果页“本地资源”标签仅在离线模式出现；自动/AI 模式不显示该标签，实际来源和 AI 标记仍如实保留。

## 查询与练习

所有查询结果都有练习入口，即使未命中本地词条。可选单选、判断、选词填空，支持多种组合及 3/5/10 题。

有本地义项时引用给定 entryId/senseId；未收录时允许 AI 基于当前查询、可用译文及语言知识生成，使用 `query` 作为依据标识，并明确不是词库收录或人工审校答案。不再因为本地词条为空拒绝全部在线出题。

离线仍只能依据已收录题目组卷，可将单选题转换为判断/选词填空；没有关联题目时提示配置 AI 在线生成，不随机用无关题目代替当前查询，也不在离线模式偷偷联网。选词填空为四选项填空，不是自由输入评分；当前不含多选题。

错题本按题列出，可编辑题干、选项、答案和解析，保留原题 ID 和答错记录，不修改只读资源包。修改后的快照优先于资源题目，复练和备份使用修订内容。编辑采用全屏滚动表单，保存/取消固定在顶部，避免键盘遮挡。

AI 响应严格按 UTF-8 解码，损坏字节不直接显示。题目与译文清理重复的 Unicode 转义，拒绝替换字符、无效代理字符和异常控制字符。已经无法还原的历史乱码不凭空猜测；备份保留原记录，可在错题编辑中修订。

## API 管理

AI 设置 → 添加 API，填写可选名称、厂商、地址、Key 和模型。保存后进入 API 管理，可切换使用/编辑或删除，最多 20 个。旧版本的单个配置自动保留为一个配置，无需重新输入 Key。

每份 API 配置保存独立的加密密钥、模型与最近测试结果。保存并测试连接实际成功后显示“连接成功 · 上次测试通过”；改地址、协议、模型或密钥后需要重新测试。状态是最近测试结果，不代表网络永远在线。切换 API 会取消在途查询和练习，刷新模型目录时使用新配置对应的密钥。切换后不复用旧账号的模型列表。

API 配置及 Key 不进入用户学习备份；Android Keystore 加密规则保留。

## Skills

AI 设置 → Skills 管理，可查看两个内置技能：双向翻译与解析、查询内容出题。内置规则为只读说明；自建技能可设置名称、指令、翻译/练习/两者的作用范围，并启停、编辑或删除。

最多 30 个自建技能，名称 60 字、单条指令 4000 字，启用技能总长度不超过 24000 字（含标题余量）。指令按任务范围拼入请求，未启用或范围不符的技能不发送。技能用于教学风格和任务要求，不执行手机代码，也不会绕过题目结构和来源校验。修改从下一次请求生效。

自建 Skills 随用户数据导出/恢复；清除 API 配置不删除自建技能。用户数据库升级到 3，仅给题目快照增加类型与编辑标记。备份 schema=2，继续读取 schema=1 的旧备份；新版备份需使用 0.6.0 或更高版本导入。重复 ID 保留本机记录，技能合并超过数量/长度限制会在修改数据前拒绝，不静默丢弃。
