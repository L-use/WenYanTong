核对入口（2026-11-20）：

- 《论语·学而》：https://ctext.org/analects/xue-er/zh 。另含为政、里仁、颜渊、述而章句，出处逐条注明。
- 周敦颐《爱莲说》：https://zh.wikisource.org/wiki/愛蓮說 。页面标明古代作品公有领域；只使用古文，现代教学内容自行编写。
- 诸葛亮《诫子书》：https://zh.wikisource.org/wiki/誡子書 。有“澹泊”“慆慢”“冶性”等异文；本库节选使用通行教学写法“淡泊”，在解析说明。
- 范仲淹《岳阳楼记》：https://zh.wikisource.org/wiki/岳陽樓記 。核对“百废具兴”“不以物喜，不以己悲”“先天下之忧而忧”等节选。
