# AI 渠道配置与学习流程

“设置 → AI 设置”支持 HTTPS Base URL、实际模型 ID、API Key。可选 Chat Completions 兼容或 Claude Messages 协议；地址可填写服务根地址或完整终点，避免重复拼接。0.5.1 支持 14 个厂商/平台预设，输入 Key 自动获取目录、搜索和选择模型；不猜测账号权限或替用户注册服务，详见 AI_MODEL_DISCOVERY.md。

“保存并启用自动模式”明确切换为自动模式；“仅保存”不改变当前模式；“保存并测试连接”会对填写的渠道发一次短请求，成功代表返回有效文本，不代表所有模型能力都已校验。

0.6.0 支持多 API 管理和最近测试状态，以及用户自建 Skills。操作、备份兼容和编辑说明见 LEARNING_0.6.0.md。

0.6.1 出题请求只提供所选题型的规则和有效示例；兼容常见题型别名。收到题型/格式/引用不合要求的批次最多重新生成一次，可能多一次 API 费用。认证、网络失败不自动重试；取消后停止。真正不符合题型的题目不会被强制改名放行。

## 模式与命中

- 离线：不发模型请求，使用下载库与内置内容。
- 自动：本地命中完整词条或整句时优先显示本地；缺少完整对照时，可结合当前查询和少量相关词义请求 AI。
- AI：结合已匹配本地词义请求模型；输出单独标为 AI 参考，保留本地释义与来源。失败不伪造译文，保留本地结果并提示原因。

词条命中、部分字词命中和整句译文分开展示。“之”等已收录词直接显示释义，不再把缺少整句译文当作词条未收录。英文词在 English → 中文及全局词典中不区分大小写检索。

## 练习

练习可选择单选、判断、选词填空，以及 AI 出题或离线题库。AI 使用当前结果及最多 6 个相关词条、各至多 3 条义项；请求附带词条 ID、义项 ID、例句和出处。模型返回 JSON，客户端核对题量、所选题型、选项、答案范围和引用后才保存。结构检查不能保证语义绝对正确，始终保留 AI 标记和依据。

无相关词条时也可根据当前查询及语言知识生成，使用 query 标识，不编造词库收录或书籍出处。配置缺失、网络失败或额度限制时可重试；有对应离线题目时也可选择本地题库。离线模式勾选 AI 会说明需切换模式，不静默联网。

题目快照写入 personal.db，用户数据库升级至 schema=3，保留既有记录，新增题型和编辑标记。错题支持编辑；快照可离线复练，资源包删除后仍保留题干和解析。学习备份 schema=2 包含题目修订和自建 Skills，继续兼容旧 schema=1 的备份。

## 凭据及网络

API Key 用 Android Keystore AES/GCM 加密，保存在私有 ai_private 偏好中。模型请求内不携带整个词库、历史记录或密钥字段，密钥仅用于配置渠道的认证头。更换地址或协议必须重新填写密钥，不能把旧渠道密钥带到新地址。拒绝 URL 中的账号、查询参数和片段，只接受 HTTPS，不携带密钥跟随重定向。响应有大小、时间限制，请求取消时断开连接。

自动备份与设备迁移排除私有偏好，手动学习数据导出不包含 API 配置及密钥。出题快照可导出，密钥不会混入解析或来源。服务商可能对调用收费，设置和 AI 练习选项均说明发送范围。

## 验证范围

单元与设备测试覆盖地址约束、协议报文、拒绝凭据跳转、Keystore 密文保存/解密、自动模式本地优先、模拟缺失译文补充、受义项约束的出题、错误引用拒绝、AI 错题和备份恢复，以及页面配置和命中提示。未提供用户真实服务商 Key，因此没有用私人或环境凭据发起计费模型请求；用户安装后可在手机测试自己的渠道。
