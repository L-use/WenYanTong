# 0.6.1 验证

用户截图显示选择单选题、5 题，但提示“AI 题型与所选范围不符”。该提示来自客户端接收到已识别但未选择的题型之后的校验。代码检查发现旧提示同时列出三种题型并以“允许题型”占位，不含具体有效类型示例，且不合要求后直接终止。没有用户的真实响应正文，不能确定其服务商具体返回了哪一题型。

新增 4 项设备回归：

- 模拟仅选单选 5 题，第一次返回 5 道判断题，自动纠正后返回 5 道有效单选；断言系统规则不再列出另外两种题型。
- 中文/英文别名与单一题型漏字段兼容；真实不匹配题型及错误选项数仍拒绝。
- 无效来源连续返回两次后停止，不绕过来源校验、不无限重试。
- 网络故障与取消只请求一次，不触发额外调用。
