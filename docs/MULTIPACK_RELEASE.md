# 多资源包发布与客户端使用

0.4.0 起，资源包独立安装、更新和删除，目录与 APK 更新渠道分开。首次开放 8 个可选包：常用基础库、说文字书、古文观止译注、CCTC 对照、经籍原文、史籍原文、资治通鉴原文、通假字。两个未明确许可的候选来源未公开分发。

0.5.0 增加六级词汇与四六级词频两个独立英文包，共 10 包。手机资源页支持中文/英文及资源类型分类，全部按包自由下载；英文来源与非商业许可限制见 ENGLISH_PACKS.md。

## 用户操作

设置 → 离线资源 → 检查资源更新。在感兴趣的包下点击“下载此包”，无需全部下载。每包展示名称、版本、大小、内容数量、许可证和审校说明。已安装包单独显示“更新此包”或“删除”；删除前确认，仅移除该包，保留用户记录及其他包。

全局查词使用所有已下载包；同字合并为一个入口，释义按需读取，保留各包来源，完全相同的释义/例句/译文可合并并列出全部来源。不同译文在结果中单独展示。异体字按包内索引关联。“查看完整来源”可展开原书、位置、上游文件与版本链接、AI/原文等属性。

资源页“浏览此包”可分页查看篇目，按标题或作者搜索；字书包请使用全局查词。经籍、史籍和资治通鉴只含原文；古文观止译注由上游 AI 生成，未经逐条学术审校。旧版下载的基础库自动迁移，内置示例始终可用。

## 检查更新接口

`https://github.com/L-use/WenYanTong/releases/download/resources-v2/resources.json`

公开 JSON，无需 Token。schemaVersion=2，packs 数组每项包含 id、title、version、revision、tag、url、bytes、sha256、minAppVersionCode、entryCount、articleCount、notes、license、reviewStatus。客户端按包 ID 比较 revision。旧 `resources-v1` 保留供 0.3 使用，不把多包目录写入旧接口。

## 本机发布

1. 准备资源数据，运行相应构建器和测试。用户提供清单的六包见 USER_RESOURCE_COLLECTION.md，说文字书见 SHUOWEN_PACK.md。
2. 每包保持稳定 ID 与记录命名空间；修改内容时递增该包 version/revision。更新一个包不要求其他包递增。许可、上游固定版本和修改说明随包保留。
3. 提交源代码和版本配置后，执行 `python tools/release/publish_catalog.py`。脚本验证本地 ZIP 和数据库哈希，逐包发布版本标签，已存在版本必须与公开附件哈希一致，不能覆盖。
4. 所有包可下载后才更新固定 `resources-v2` 索引。每个资源 Release 均设 `--latest=false`，APK latest 不受影响。发布脚本可安全重试已上传的相同附件。
5. 应用版本按原流程 `tools/release/publish.ps1` 本地构建、签名和发布，不用 Actions，密钥不上传。

ZIP 包含 manifest.json 和 sample.db。schema=1 的旧基础库与 schema=2 多包均可读；新版基础库以外的包使用各自的 ID。单个数据库上限 128 MiB，下载 ZIP 64 MiB，manifest 256 KiB，最多同时安装 20 包。解压拒绝多余/重复文件和目录越界，验证哈希、SQLite 完整性、外键、结构、字段、数量和兼容版本，再登记安装指针。查询和连接更换互斥；新数据库分开存放，用户数据库不替换。

下载目录由 GitHub HTTPS 及维护者发布权限保证来源，SHA256 检查传输完整性；尚未提供独立离线数字签名。本地 ZIP 需由用户确认可信。程序不执行包内代码。首次启动重新校验已安装数据库；损坏包跳过，其余包与内置示例继续使用。
