文言通 0.4.0：资源包自由选择。

- 新增独立资源目录，8 个可选包分别下载、更新、删除，也可导入本地 ZIP。旧版已下载基础库自动保留，内置示例始终可用。
- 新增古文观止译注、CCTC 白话对照、经籍原文、史籍原文、资治通鉴原文和通假字包；《说文解字》作为可选进阶字书。
- 查词覆盖全部已下载包，同字聚合展示，保留不同释义和来源；释义按需加载，可查看原书、文件、位置、版本和整理属性。
- 古文篇目分页浏览、按标题/作者搜索，长篇正文按段加载；不同译文独立展示出处。
- 古文观止现代译注由上游 AI 生成，未经逐条学术审校；经籍和史籍等原文包没有白话译文。未找到明确再分发许可的两个来源未收入发布包。
- 个人历史、收藏和错题与资源独立保存；单包删除不影响其他包。应用与资源发布不使用 GitHub Actions。

使用：设置 → 离线资源 → 检查资源更新 → 在需要的包下点击“下载此包”。下载完成后进入“全局查词”或“浏览此包”。首次目录检查在离线模式需确认连接 GitHub。
